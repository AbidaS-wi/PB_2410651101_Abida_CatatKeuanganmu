# Catat Keuanganmu

Aplikasi pencatat keuangan sederhana untuk mahasiswa, dibuat dengan Flutter.
Fitur: mencatat pengeluaran secara detail, kalkulasi sisa anggaran, dan
melihat seluruh riwayat transaksi.
